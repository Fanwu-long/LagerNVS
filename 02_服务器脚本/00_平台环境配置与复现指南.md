### 数据准备（500 场景子集，仿 I3DM 精准下载法）

```bash
# 1. 分析官方场景列表 → 文件映射，只下载覆盖 500 场景的 45 个 .torch 文件（4.5GB，全量 55.6GB）
#    数据源：HF yiren-lu/re10k_pixelsplat（走 hf-mirror）
python ~/dl500.py            # 4 线程并行下载，DNS 瞬断重跑即可（幂等）

# 2. 解包成 images/ + metadata/ + full_list.txt（登录节点 CPU，约 5 分钟）
python ~/lagernvs/process_data.py --mode test \
  --base_path ~/.cache/huggingface/hub/datasets--yiren-lu--re10k_pixelsplat/snapshots/<hash>/ \
  --output_dir ~/data_eval/re10k/ --num_processes 16

# 3. 生成 500 场景子集视图列表（FixedViewSelector 直接读 keys）
python -c "import json; d=json.load(open('assets/re10k_2v.json')); json.dump({k:d[k] for k in list(d)[:500]}, open('assets/re10k_2v_500.json','w'))"

# 4. 提交评测
sbatch scripts/eval500.sbatch
```

## 快速开始（3 步跑通推理）

### 第 1 步：上传代码到平台

把整个 `[代码]_lagernvs-main` 目录上传到平台 `~/LagerNVS/`：

```bash
# 在平台 Shell 中执行
cd ~
# 方法1: 直接 git clone（推荐，如果能访问 GitHub）
git clone https://github.com/facebookresearch/lagernvs.git LagerNVS

# 方法2: 用 GUI 文件上传功能上传 zip 然后解压
unzip lagernvs-main.zip
mv lagernvs-main LagerNVS
```

把本 `scripts/` 目录也上传到 `~/LagerNVS/scripts/`。

### 第 2 步：配置 HF Token

```bash
mkdir -p ~/.cache/huggingface
echo "你的_hf_token_粘贴在这里" > ~/.cache/huggingface/token
```

验证 token 有效：
```bash
python -c "from huggingface_hub import list_repo_files; print('\n'.join(list_repo_files('facebook/lagernvs_general_512')))"
```

### 第 3 步：搭建环境 + Smoke Test

```bash
# 1. 搭建环境（登录节点执行，约 10-20 分钟）
cd ~/LagerNVS
bash scripts/01_setup_env.sh

# 2. 准备测试图片（上传 2 张到 test_data/demo/）
mkdir -p test_data/demo
# 用 GUI 上传几张 .jpg 或 .png 图片到这个目录

# 3. 提交 smoke test 作业
sbatch scripts/02_smoke_infer.sbatch

# 4. 查看作业状态
squeue -u "$USER"

# 5. 查看日志
tail -f logs/lagernvs_smoke-*.out
```

成功后输出视频在 `outputs/smoke_demo.mp4`。
